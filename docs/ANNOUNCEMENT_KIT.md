## Technical launch post

# Introducing APIVault: the GitHub of APIs

Finding an API is easy. Finding one with useful, current, well-sourced information is harder.

APIVault is an open-source API discovery and verification platform built around three ideas:

- **Discovery:** browse and search a structured catalogue of APIs.
- **Verification:** inspect evidence and point-in-time verifier observations instead of relying on unsupported claims.
- **Community:** suggest APIs and corrections through a moderated contribution workflow.

The platform includes a read-only catalogue REST API, an OpenAPI specification and interactive docs, optional read-only API keys, and maintainer workflows for verification and moderation.

APIVault does not host third-party APIs or guarantee their uptime. Its goal is to make API information easier to discover, inspect and improve.

We are opening the project to developers who want to use it, improve the catalogue or contribute code.

## Demo storyboard (60–90 seconds)

1. Start on the catalogue landing page and explain the discovery problem.
2. Search for an API and narrow results using a category or filter.
3. Open a record and point out official documentation, provider details and metadata.
4. Show verification status, evidence and timestamps; explain that checks are point-in-time signals.
5. Open /docs, show the OpenAPI reference and make a safe read-only catalogue request.
6. Show how a user suggests an API or correction and explain moderation.
7. End with the repository, contribution guide and call for useful feedback.

Use a production-like environment with non-sensitive data. Do not show secrets, private account details or fabricated records.
